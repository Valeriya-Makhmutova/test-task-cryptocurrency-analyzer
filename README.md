# Приложение для анализа криптовалют

Консольное приложение на Python, которое запрашивает
данные о криптовалютах через публичное API (CoinGecko API), обрабатывает их и сохраняет
результат в отформатированный файл Excel.

## Требования

Для работы приложения необходим Python версии 3.0 и выше.

## Установка

1. Склонируйте себе на компьютер репозиторий с проектом с помощью ```git clone```.
2. Установите необходимые зависимости:

```bash
pip3 install -r requirements.txt
```

## Запуск приложения

Запуск приложения выполняется через командную строку и файл main:


*В этом случае применятся аргументы по умолчанию*
```bash
python3 main.py 
```

*Но можно передать и собственные значения аргументов, например*
```bash
python3 main.py  [--currency="eur"] [--limit=50] [--marketCapLine=5000000000]
```

Если запуск пройдет успешно и данные запишутся в Excel файл, то в консоли появится запись:

```
Данные успешно сохранены в файл 'output.xlsx'
```
Если файл 'output.xlsx' существует, то он перезапишется. 
Если файл 'output.xlsx' не существует, то он создастся.

### Параметры запуска

Приложение принимает три опциональных аргумента командной строки. 
Если аргументы не переданы, используются значения по умолчанию.

* **currency**: Сравнимая криптовалюта (значение по умолчанию: "usd").
* **limit**: Максимальное количество криптовалют на странице (значение по умолчанию: 25).
* **marketCapLine**: Минимальный порог для значения капитализации рынка валюты (значение по умолчанию: 1000000000).

Все значения по умолчанию можно увидеть в файле ```config.py```

### Примеры команд

Запуск со значениями по умолчанию:
```bash
python3 main.py  
```

Запуск с указанием пользовательских аргументов:
```bash
python3 main.py  --currency="eur" --limit="20" --marketCapLine=3000000000
```
